# Purpose

QuitTrack is a Progressive Web App (PWA) to help people quit smoking. It provides a mobile-friendly, installable experience that helps users track progress, stay motivated, and view improvements in health and finances after quitting.

Key features (expected/implemented in the app):

- Track smoke-free days and streaks
- Show health milestones and improvements over time
- Display money saved since quitting
- Provide motivational messages and tips
- Offline support and installable as a PWA
